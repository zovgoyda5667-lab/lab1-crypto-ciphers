# Lab1 Crypto Ciphers

Консольное приложение на C# (.NET 8) для лабораторной работы №1 «Методы и средства криптографической защиты информации».

## Состав

- `Program.cs` — исходный код программы (взлом модифицированного шифра Цезаря, взлом модифицированного шифра Виженера, расшифровка шифра Плейфера).
- `Lab1Crypto.csproj` — файл проекта .NET.
- `REPORT.md` — отчёт по лабораторной работе.

## Запуск

```bash
dotnet run
```
